# Demo assets

The shapes are original procedural artwork generated by `course_utils.py`.
No external dataset or account is needed for the core data exercises.

`scripts/prepare_demo.py` downloads `bus.jpg` from the
[Ultralytics assets repository](https://github.com/ultralytics/assets/blob/main/im/bus.jpg).
This third-party sample is used for a classroom inference example; its rights remain
with its owners. The course does not relicense that image or pretrained weights.
`bus_pan.avi` is an artificial pan of this still image, useful for API demonstrations,
not evidence of tracking accuracy on a genuine video dataset.

YOLO weights download from Ultralytics on first use. Faster R-CNN weights download
from PyTorch on first use. Consult their project terms when using them beyond class.
